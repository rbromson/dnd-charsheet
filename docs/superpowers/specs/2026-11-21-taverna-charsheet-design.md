# «Таверна» — лист персонажа и журнал (PWA) — дизайн

Дата: 2026-11-21. Статус: утверждено пользователем («Да, ок», «Делаем всё до победы»).

## Зачем

Пользователь впервые играет в настольную РПГ (скорее всего D&D 5e, редакция неизвестна), класс и мир самодельные. Нужен личный лист персонажа на планшете Redmi Pad 2 Pro (Android 16) и журнал, который заполняется сам во время партии. D&D 5e — только шаблон: любое вычисленное число можно переопределить. Первое реальное использование — завтра.

## Цели / не-цели / анти-цели

- Цели: лист (стр. 1 PDF), ресурсы и отдых, кубики с домашними правилами, заклинания (стр. 3), «Персонаж» (стр. 2), журнал со справочником и секретами, режим записи сессии с распознаванием речи, галерея картинок, резервная копия.
- Не-цели: аккаунты, облако, мультиплеер, базы правил/заклинаний/предметов, мастер создания персонажа, проверка по правилам, логотипы/арт/шрифты D&D.
- Анти-цели: потерять данные; случайно изменить лист тапом во время игры; показать секреты соседям по столу; интерфейс, который нельзя нажать пальцем (< 48 px).

## Платформа (решение пользователя: PWA вместо Android-приложения)

- Svelte 5 + TypeScript + Vite, `vite-plugin-pwa` (офлайн, установка на главный экран), хостинг GitHub Pages (публичный репозиторий `dnd-charsheet`, данные только на устройстве).
- Хранение: IndexedDB (`idb`). Лист персонажа — один JSON-документ (поля добавляются без миграций, недостающие заполняются значениями по умолчанию при загрузке). Журнал, справочник, медиа — отдельные хранилища с индексом по персонажу. Запрашивается `navigator.storage.persist()`.
- Шрифты вшиты (`@fontsource`): Alegreya / Alegreya SC (заголовки, числа), Inter (текст), Marck Script (только секреты).
- Все строки интерфейса — в `src/lib/i18n/uk/*.ts` (украинский, подписи из PDF).

### Approaches (рассмотренные)

1. Android-нативно (Kotlin + Compose + Room) — отвергнуто пользователем: тяжёлая установка SDK, медленный цикл правок.
2. Одиночный HTML-файл — отвергнут: Chrome Android ненадёжно работает с file:// и хранилищем.
3. **PWA на GitHub Pages — выбрано**: быстрые правки, офлайн, все нужные API (вибрация, «Поделиться», микрофон, wake lock) доступны.

Хранилище: A) нормализованные таблицы, Б) один JSON-файл, **В) гибрид — выбран** (лист документом, журнал таблицами).

## Визуальная концепция (утверждена, макет `.superpowers/brainstorm/*/content/visual-concept-v2.html`)

- Тёмный фон «закопчённое дерево» с тёплым свечением; карточки цвета пергамента с тёмным «чернильным» текстом.
- Акцент — тлеющие угли `#e8743b` (интерфейс); золото `#e6b450` — только успех (натуральная 20, закреплённое).
- Плитки боя (КД, Ініціатива, Швидкість, Бонус майстерності) — насыщенные тёплые цвета (угли, охра, вино, бирюза).
- Характеристики — «щиты»: крупный модификатор, значение в овале.
- Боковая навигация (rail): портрет (переключатель персонажей) · Аркуш · Бій · Заклинання · Спорядження · Персонаж · Журнал · Кубики · FAB «швидка нотатка».
- Альбомная ориентация: 2–3 колонки; книжная: одна.
- Домашние правила видны: навык через другую характеристику подсвечен «⇄», метки «мін 8», «переброс 1».

## Режимы взаимодействия (утверждено)

- **Гра** (по умолчанию): тап по навыку/спасброску/атаке/инициативе = бросок. Живые значения меняются на месте: хиты, ресурсы, ячейки, кости хитов, спасброски от смерти, монеты, вдохновение. Долгий тап по любому элементу — карточка его настроек.
- **Правка** (карандаш в шапке): все поля редактируемые, у списков «додати / видалити / перемістити».
- После заметного действия (урон, лечение, отдых, удаление, трата ресурса) — тост «Скасувати» (undo).

## Полный перечень действий пользователя

Персонажи: создать (пустой шаблон 5e), дублировать, удалить (подтверждение), переключить (портрет в rail → панель), выбрать портрет из галереи, экспорт, импорт.

Аркуш: имя, класс, уровень, раса, предыстория, мировоззрение, опыт, имя игрока; 6 характеристик (значение); бонус мастерства (авто по уровню / ручное); спасброски (владение, доп. бонус, ручное); 18 навыков (владение/экспертиза, характеристика, доп. бонус, ручное, мин. на d20, заметка); пассивная внимательность (авто/доп./ручное); вдохновение; умения и особенности (карточки название+текст: добавить/редактировать/удалить/порядок); владения и языки (текст).

Бій: КД, инициатива (авто/доп./ручное), скорость; хиты: максимум, текущее, временное; урон/лечение цифровой клавиатурой (урон сначала снимает временные); кости хитов (кость, всего, потрачено; «потратить» = бросок + лечение); спасброски от смерти (3+3, тап; бросок d20); атаки (название, характеристика или нет, владение, доп. бонус, ручное, формула урона `1d6+МОД`, тип урона, заметка; бросок попадания и урона, крит удваивает кости); ресурсы (название, максимум, текущее, кость, восстановление: короткий/длинный/вручную, максимум за бросок; трата/возврат тапом); короткий и длинный отдых (с подтверждением, показом что восстановится, undo); глобальное правило «перебрасывать 1».

Кубики: лоток (d4…d100, количество, преимущество/помеха), удержание = «трясти», история последних бросков; после броска проверки — «докинуть кость ресурса» (списывает единицу, учитывает максимум за бросок).

Заклинання: показать/скрыть раздел; класс заклинателя; базовая характеристика; СЛ и бонус атаки (авто/ручное); слоты 1–9 (всего, тап — потратить/вернуть); заклинания (уровень 0–9, название, подготовлено, описание; добавить/удалить).

Спорядження: предметы (название, количество, описание, магический; добавить/удалить/порядок); монеты ММ/СМ/ЕМ/ЗМ/ПМ (±, ввод); колоды (название, список карт; тянуть случайную, вернуть всё) — для «Колоди ілюзій».

Персонаж: возраст, рост, вес, глаза, кожа, волосы, внешность, предыстория, союзники и организации, другие умения, сокровища, черты характера, идеалы, привязанности, слабости, секрет персонажа; галерея картинок (добавить из галереи/камеры, просмотр, удалить, сделать портретом).

Журнал: записи сессий (номер и дата проставляются сами, редактируемы; заголовок; текст с @-упоминаниями; секрет; картинки; закрепить; удалить); быстрая заметка с любого экрана (FAB, попадает в текущую сессию); поиск; справочник NPC / місця / завдання (название, описание, статус, секрет, картинки, «Де згадувався»); переименование в справочнике обновляет упоминания.

Режим сесії (аудио): старт/стоп; уровень звука и ползунок порога; запись идёт только когда громче порога (пауза в тишине, предзапись 0,5 с, закрытие фрагмента после 1,5 с тишины); каждый фрагмент → текст в журнал текущей сессии в реальном времени; движок распознавания: Chrome (онлайн) / Whisper на устройстве / выключено; язык распознавания; хранить аудио да/нет; «Розпізнати» для фрагментов без текста; «Надіслати в Claude» — только ещё не отправленные фрагменты + список имён из справочника + готовая просьба о конспекте, через системное «Поделиться» (Claude принимает текст, не аудио); экран не гаснет во время сессии.

Резервная копия: экспорт персонажа (лист + журнал + справочник + картинки, аудио по галочке) в ZIP через «Поделиться»/скачивание; импорт ZIP (и старого JSON) как нового персонажа.

## Расчёты (по умолчанию 5e, всё переопределяемо)

- Модификатор = ⌊(значение − 10) / 2⌋. Бонус мастерства = 2 + ⌊(уровень − 1) / 4⌋.
- Навык/спасбросок = ручное ?? (мод(характеристика) + владение × БМ + доп.), экспертиза = 2 × БМ.
- Пассивная внимательность = ручное ?? 10 + навык «Уважність» + доп.
- Инициатива = ручное ?? мод(Впр) + доп.
- Атака = ручное ?? мод(хар.) + (владение ? БМ : 0) + доп.; `МОД`/`MOD` в формуле урона = мод характеристики атаки.
- СЛ заклинаний = 8 + БМ + мод; бонус атаки заклинаний = БМ + мод (оба переопределяемы).
- Урон: сначала временные хиты, потом текущие (не ниже 0). Лечение: до максимума.
- Короткий отдых: ресурсы «короткий» → максимум. Длинный: все ресурсы «короткий»/«длинный» → максимум, хиты → максимум, временные → 0, кости хитов восстанавливаются на половину (мин. 1), спасброски от смерти сбрасываются, ячейки заклинаний сбрасываются.
- d20: переброс 1 (один раз, если включено) → минимум на d20 (если задан у навыка) → выбор при преимуществе/помехе. Крит/провал — по грани кости после переброса, до минимума.

## Риски

- Распознавание речи на Android не проверено (качество украинского, писк при перезапуске Web Speech, конфликт микрофона, скорость Whisper). Поэтому три движка и настройка; аудио фрагментов сохраняется независимо от распознавания.
- Запись почти наверняка останавливается при блокировке экрана → wake lock и предупреждение в интерфейсе.
- Данные браузера: persist() + напоминание об экспорте раз в N дней.

## Оставлено исполнителю

Иконки, точные отступы, анимации (бросок 0,6–0,8 с, вибрация `navigator.vibrate`), внутреннее устройство компонентов.
