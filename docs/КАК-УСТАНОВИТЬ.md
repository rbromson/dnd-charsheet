# Как поставить «Таверну» на планшет

Адрес приложения: **https://rbromson.github.io/dnd-charsheet/**

## Установка (один раз, ~1 минута)

1. На планшете откройте **Chrome** (именно Chrome, не встроенный браузер Xiaomi).
2. Откройте адрес выше.
3. Нажмите **⋮** (три точки справа вверху) → **«Добавить на главный экран»** (или «Установить приложение») → **«Установить»**.
4. На рабочем столе появится иконка «Таверна». Дальше открывайте приложение с неё: оно запускается на весь экран и работает без интернета.

Если пункта «Установить» нет: обновите страницу один раз и подождите 5–10 секунд. Приложению нужно скачаться целиком.

## Перед первой игрой

- **Фридо уже заведён.** Цифры предварительные, поправьте их в режиме **«Правка»** (переключатель справа вверху).
- **Гра / Правка:**
  - в режиме «Гра» тап по навыку бросает кубик, а долгий тап открывает его настройки;
  - в режиме «Правка» можно менять всё.
- **Микрофон** для режима записи сессии: при первом запуске записи Chrome спросит разрешение. Нажмите «Разрешить».
- **Xiaomi / HyperOS любит усыплять приложения.** Чтобы запись не обрывалась, сделайте так:
  - Настройки → Приложения → **Chrome** → Контроль активности → **«Нет ограничений»**;
  - во время записи не гасите экран: приложение само держит его включённым.

## Режим записи сессии: что проверить завтра

1. Откройте **Журнал**, создайте сессию, нажмите **«Почати запис сесії»**.
2. В настройках записи попробуйте по очереди движки распознавания:
   - **Chrome (онлайн)** — нужен интернет, обычно хорошо понимает украинский;
   - **Whisper на пристрої** — один раз скачивает модель (сотни МБ, лучше по Wi-Fi), потом работает без интернета. Неизвестно, хватит ли скорости планшета;
   - **Без розпізнавання** — только записывает звук фрагментами.
3. Подвигайте ползунок порога, чтобы запись не включалась от фонового шума.
4. Кнопка **«Надіслати в Claude»** откроет окно «Поделиться». Выберите приложение Claude, и в нём появится текст сессии с просьбой сделать конспект. Готовый конспект вставьте обратно в запись журнала.

Запишите, что работало, а что нет. По этим заметкам доделаем.

## Резервная копия

Данные хранятся **только на планшете**. Время от времени делайте копию:

1. Тап по портрету слева вверху → **⋯** у персонажа → **«Експорт у файл»**.
2. Сохраните файл (например, в Google Диск или Telegram «Избранное»).

Восстановить данные из копии: та же панель → **«Імпорт»**.

Никогда не очищайте данные Chrome для этого сайта, иначе персонаж пропадёт.

## Обновления

Когда приложение обновляется, новая версия подтягивается сама, если планшет в сети. Достаточно закрыть приложение и открыть его снова.
