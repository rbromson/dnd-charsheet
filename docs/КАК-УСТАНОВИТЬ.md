# Как поставить «Таверну» на планшет

Адрес приложения: **https://rbromson.github.io/dnd-charsheet/**

## Установка (один раз, ~1 минута)

1. На планшете откройте **Chrome** (именно Chrome, не встроенный браузер Xiaomi).
2. Откройте адрес выше.
3. Нажмите **⋮** (три точки справа вверху) → **«Добавить на главный экран»** (или «Установить приложение») → **«Установить»**.
4. На рабочем столе появится иконка «Таверна». Дальше открывайте приложение с неё: оно запускается на весь экран и работает без интернета.

Если пункта «Установить» нет: обновите страницу один раз и подождите 5–10 секунд. Приложению нужно скачаться целиком.

## На телефоне

Ставится так же: Chrome → ⋮ → «Добавить на главный экран».

На телефоне вид другой:
- разделы внизу экрана;
- портрет слева вверху открывает список персонажей;
- справа вверху три кнопки: «Кубики», «перо» (быстрая заметка) и «карандаш» (режим «Правка»; когда он включён, иконка становится галочкой).

Данные телефона и планшета **не синхронизируются**: у каждого устройства своя копия. Чтобы перенести персонажа, сделайте «Експорт у файл» на одном устройстве и «Імпорт» на другом.

## Перед первой игрой

- **Приложение стартует пустым.** Чтобы завести Фрідо, нажмите **«Імпорт»** и выберите файл из «Загрузок»:
  - `Фрідо_Брецель_Простолюдин_1.zip` — основной лист 1 уровня;
  - `Фрідо_Брецель_Вампір_5.zip` — лист «на випадок звернення» от майстра.

  Файлы сначала перенесите на планшет (Telegram, Google Drive, кабель). Импорт всегда создаёт нового персонажа и ничего не перезаписывает.
- **Шаблон для ИИ** — для друзей со своими листами: кнопка «Шаблон для ШІ» на стартовом экране и в панели персонажей скачивает JSON с инструкцией. Отдайте его ChatGPT/Claude вместе с листом (PDF, фото, текст), попросите заполнить, сохраните ответ как `.json` и загрузите через «Імпорт». Шаблоны на двух языках уже лежат в «Загрузках».
- **Язык интерфейса** — «Українська / English»: на стартовом экране и внизу панели персонажей (тап по портрету). При переключении страница перезагрузится. Библиотека SRD тоже переключается на английский оригинал; в украинском режиме у предметов из библиотеки видно английское название.
- **Гра / Правка:**
  - в режиме «Гра» тап по навыку открывает окно броска: там выбираете «Перешкода / Звичайний / Перевага» и бросаете вторым нажатием на кубик; долгий тап открывает настройки навыка;
  - в режиме «Правка» можно менять всё.
- **Микрофон** для режима записи сессии: при первом запуске записи Chrome спросит разрешение. Нажмите «Разрешить».
- **Xiaomi / HyperOS любит усыплять приложения.** Чтобы запись не обрывалась, сделайте так:
  - Настройки → Приложения → **Chrome** → Контроль активности → **«Нет ограничений»**;
  - во время записи не гасите экран: приложение само держит его включённым.

## Режим записи сессии: что проверить завтра

1. Откройте **Журнал**, создайте сессию, нажмите **«Почати запис сесії»**.
2. В настройках записи попробуйте по очереди движки распознавания:
   - **Chrome (онлайн)** — нужен интернет, обычно хорошо понимает украинский;
   - **Whisper на пристрої** — один раз скачивает модель (сотни МБ, лучше по Wi-Fi), потом работает без интернета. Неизвестно, хватит ли скорости планшета;
   - **Без розпізнавання** — только записывает звук фрагментами.
3. Подвигайте ползунок порога, чтобы запись не включалась от фонового шума.
4. Кнопка **«Надіслати в Claude»** откроет окно «Поделиться». Выберите приложение Claude, и в нём появится текст сессии с просьбой сделать конспект. Готовый конспект вставьте обратно в запись журнала.

Запишите, что работало, а что нет. По этим заметкам доделаем.

## Оружие из снаряжения

Включите у предмета в «Спорядження» переключатель **«Зброя — показувати в атаках»**, и предмет появится на вкладке «Бій» как атака:
- имя атаки меняется вместе с именем предмета;
- удалили предмет — исчезла и атака;
- урон и характеристика настраиваются кнопкой «Налаштувати атаку».

## Библиотека предметов и заклинаний (SRD 5e)

На вкладках «Спорядження» и «Заклинання» вверху кнопка **«З бібліотеки»**: поиск по-украински или по-английски, категории, полное описание.
- Оружие сразу становится атакой с правильным кубиком; для «Зброя +1», «Вогняний язик» и т. п. выбираете основу (довгий меч, лук…).
- Доспех и щит: включите в плитке КО «Рахувати від спорядження» — КО посчитается сам. Если КО вписан вручную (как у Фрідо), к нему всё равно добавятся налаштовані плащ/перстень захисту.
- Волшебные предметы: в карточке предмета переключатели «Вдягнено» и «Налаштовано» (видно «n з 3»). Бонусы к КО/рятункам и «Сила стає 19» работают, только когда предмет надет и налаштований.
- Заряды (жезлы, посохи) появляются в «Ресурсах» на вкладке «Бій».
- Заклинание можно добавить просто в книгу или **«й в атаки»** — тогда оно бросается как атака заклинанием или показывает СК рятунку; кубики заговора растут с уровнем.
- В библиотеке только бесплатный SRD: предметов из других книг там нет — их добавляйте вручную, как раньше.

## Обучение, аватарки, 3D-кубики

- **Обучение** открывается при первом запуске: 8 коротких карточек с анимациями. На каждой есть «Запитати свій ШІ, як це працює» — готовый вопрос о правиле уходит в выбранное приложение (Claude, ChatGPT). Повторить обучение — панель персонажей → «Як користуватися».
- **Аватарки NPC, мест и заданий**: тап по аватару в карточке довідника — выбрать картинку; или в галерее карточки «Зробити аватаркою». Первая добавленная картинка становится аватаром сама. Аватар виден в списке, в карточке и в ссылках внутри текста.
- **3D-кубики**: d4–d20 бросаются объёмными (WebGL); d100 и броски больше чем из 6 кубиков остаются плоскими. Если в системе выключены анимации — кубик сразу показывает итог.

## Персонаж текстом для ИИ

Панель персонажей (тап по портрету) → **⋯** у персонажа → **«Експорт для ШІ (текст)»**: лист, снаряжение, довідник и журнал одним текстом (секреты не попадают). Удобно, чтобы обсудить персонажа с Claude или дать ему контекст.

## Нотатки после игры → в аркуш через ИИ

Если играли без записи звука, а заметки вели на бумаге:
1. **Вкладка «Журнал» → «ШІ → аркуш» → «Поділитися інструкцією».** Инструкция уже содержит ваше снаряжение, монеты и известных NPC/места/задания, чтобы ИИ писал их точными названиями.
   Переключатель **«Разом з історією»** (включён) добавляет к инструкции весь довідник и прошлые сессии — ИИ будет дописывать существующие записи, а не заводить дубли.
2. **В Claude или ChatGPT:** вставьте инструкцию и добавьте голосовое сообщение, в котором надиктованы заметки. Можно и наоборот: надиктовать заметки прямо в приложении (журнал → режим сессии → запись) и нажать там **«Розібрати в аркуш»** — тогда расшифровка уйдёт вместе с инструкцией.
3. **ИИ ответит JSON.** Скопируйте ответ целиком (лишний текст и ```-блоки не мешают), вернитесь в «ШІ → аркуш» и нажмите **«Вставити з буфера»** (или откройте сохранённый `.json`).
4. **Проверьте список.** Каждую строку можно снять галочкой. Предметы, которых нет в снаряжении, при списании подсвечены и сняты сами. Новые предметы с официальным названием подтягиваются из библиотеки SRD.
   Для уже существующих записей видно, что будет с текстом: **«доповнити новим абзацом»**, **«перезаписати опис»** или **«опис без змін»**. ИИ сам выбирает режим (`append` — дописать только новое, `replace` — заменить описание целиком), а приложение страхует: если ИИ прислал старый текст вместе с новым, это перезапись, а не дубль. Если ИИ указал номер уже существующей сессии, он дописывает её, а не создаёт вторую.
   Ссылки `@[Ім’я]` ИИ обязан ставить везде — и в записи сессии, и в описаниях NPC, мест, заданий и предметов (кто с кем связан, кто дал задание, откуда предмет); для упомянутых новых имён он заводит записи в довіднику. Если ИИ забыл ссылку, приложение само свяжет имя, написанное так же, как в довіднику (в начальной форме: «Мірра», а не «Мірру»).
5. **«Застосувати».** Появится запись сессии в журнале, новые записи довідника, изменятся снаряжение, монеты, досвід и ОЗ. Изменения листа можно отменить кнопкой «Скасувати» в уведомлении. Запись журнала и довідника удаляются обычным способом.

## Голосовой ввод в записи

В тексте записи журнала и в быстрой заметке (перо слева внизу) есть кнопка **«Голосом»**:
- нажмите её и говорите, фразы появятся в тексте;
- **«Стоп»** — закончить.

Работает через распознавание Chrome, поэтому нужен интернет. Если в этот момент идёт запись сессии через движок Chrome, диктовка недоступна: Chrome слушает микрофон только в одном месте.

## Где хранятся данные

Всё хранится **только на планшете**, в памяти Chrome для этого сайта. Наружу уходит только то, что вы сами отправляете:
- **Звук при распознавании через Chrome** (движок «Chrome» и кнопка «Голосом») отправляется на серверы Google. Так устроено распознавание речи в Chrome, сохраняется у вас только текст.
- **Whisper** распознаёт прямо на планшете, ничего не отправляя.
- **Текст сессии** уходит в Claude только по кнопке «Надіслати в Claude».

## Резервная копия

Данные хранятся **только на планшете**. Время от времени делайте копию:

1. Тап по портрету слева вверху → **⋯** у персонажа → **«Експорт у файл»**.
2. Сохраните файл (например, в Google Диск или Telegram «Избранное»).

Восстановить данные из копии: та же панель → **«Імпорт»**.

Никогда не очищайте данные Chrome для этого сайта, иначе персонаж пропадёт.

## Обновления

Когда приложение обновляется, новая версия подтягивается сама, если планшет в сети. Достаточно закрыть приложение и открыть его снова.
